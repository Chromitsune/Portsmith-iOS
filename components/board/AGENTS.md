# `board` component family

This family groups Portsmith component wrappers by upstream scope, not by a promise of cross-device compatibility. Current wrappers: ShengHidInput, ShengNovatekTouch, ShengPreflight, ShengUfs. Read each child `AGENTS.md`, `README.md`, `component.toml` and source notices before use. Keep source/license pins and board-specific constraints separate; update the family index only through its documented inputs.
