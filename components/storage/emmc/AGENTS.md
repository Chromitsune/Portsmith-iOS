# eMMC component subfamily

This subfamily holds eMMC controller/boot references, currently `NativeMsdc` for MediaTek MT8167. Read the child component README, `component.toml`, source license and tests before reuse. Keep the MT8167 MSDC0 implementation separate from Qualcomm SDHCI/UFS and do not treat host compilation as a device result. Source folders are vendored snapshots; preserve their notices and pins.
