# Shared component workspace

Components are candidate source snapshots grouped by hardware/function. Read `README.md`, `manifest.toml`, each wrapper's `component.toml` and `UPSTREAM.toml`, source notices, compatibility notes and local `AGENTS.md` before reuse. Component selection is not proof of portability; keep board-specific drivers/addresses separate. Do not add source code without file-level license/provenance review. `source/` directories are vendored snapshots; do not add Portsmith instructions or unrelated code inside them.
