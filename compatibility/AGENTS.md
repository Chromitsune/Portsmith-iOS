# Compatibility data and generated reports

`ports.json` is the editable feature-status input; every row must name the exact source pin and distinguish upstream reports from Portsmith verification. `upstream-watch.json` is generated by `tools/watch-upstreams.py`; lookup failures remain review states. `docs/compatibility-matrix.html` and the marked README table are generated from `ports.json`; regenerate with `python3 tools/build-compatibility-matrix.py` and check with `--check`. Do not infer a capability from a compile, catalog status, or another device.
