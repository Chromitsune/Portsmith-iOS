# Shared source frameworks

Device repositories live in `ports/<port>/repo/` as complete source trees: most are pinned Git submodules to original maintainer repositories; Dada is a vendored snapshot pinned by commit in `manifest.toml`. This folder holds shared framework and optional research references. The common [UniXNU](UniXNU) framework is initialized with curated ports; standalone references are initialized on demand.

Use a plain clone and `python3 tools/checkout-sources.py --curated` to initialize the curated port/framework sources. Optional UniXNU device-catalog source references (72 additional submodules; sheng reuses the curated checkout) are initialized separately with `python3 tools/checkout-sources.py --name <record-name>` or `--available`. Avoid `git submodule update --init` without an explicit path selection (it initializes all direct catalog refs) and avoid `--recursive`: at the pinned UniXNU revision `e2fdae4312d0acc3d8a52bc457101e7918095e6a`, a nested `drivers/ArmCpu` gitlink references `2e11cda72740b985dedde3e32ba72b0fd64eb475`, which the upstream repository rejected as unavailable (`upload-pack: not our ref`). Portsmith does not need that nested checkout: the license-cleared component snapshots are organized under `components/` at their own catalog pins. To inspect only the framework source, use `git submodule update --init sources/UniXNU` (without `--recursive`). `sources/manifest.toml` is the workspace-wide catalog of curated port/framework pins, vendored component/catalog snapshots, optional available-device sources, and reference-only research repositories.

Do not commit Apple/vendor firmware, IPSWs, device dumps, keys, calibration data, generated images, or private build artifacts from any checkout. Preserve source licenses and notices. Vendored component snapshots include their exact source commit, URL, and original license but not the source Git history.
