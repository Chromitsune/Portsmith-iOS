# Google Pixel 4 (`flame`) port

Implementation and current status: [`repo/README.md`](repo/README.md), [`repo/HANDOFF.md`](repo/HANDOFF.md), [`repo/RECOVERY.md`](repo/RECOVERY.md), and [`repo/DEVICE.md`](repo/DEVICE.md) in the pinned `NWylynko/ios-flame` fork.

Upstream documents iOS 16.7.16/XNU with an iOS UI on the Pixel 4 and a GPU path using Mesa Turnip/metal2vulkan. Several services remain missing; do not equate UI rendering with a usable phone. Follow the port's own backup and recovery instructions, and never flash without explicit authorization.

Pixel 4 (`flame`) is Qualcomm SM8150/Snapdragon 855 with Adreno 640; its GPU/UEFI/firmware paths are not Lavender drivers.
