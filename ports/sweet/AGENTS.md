# Redmi Note 10 Pro (`sweet`) port

Implementation and authoritative current status: [`repo/README.md`](repo/README.md) and [`repo/NOTES.md`](repo/NOTES.md) in the pinned `dipa-studio/ios-sweet` fork.

Upstream reports iOS 16.7.16/XNU reaching the home screen with touch and buttons; graphics are CPU-rendered and many devices/services are incomplete. This is experimental, not a daily-use OS. It writes/erases `userdata` when installed. Never use a binary or flash procedure without user authorization, device-specific backup, and an inspected restore path.

The port is Qualcomm SM7150/Snapdragon 732G, UFS, and not a drop-in for Lavender's SDM660/eMMC board.
