# Redmi Note 10 Pro — DC28088 `ios-sweet` main

This variant tracks the maintained default `main` branch of [DC28088/ios-sweet](https://github.com/DC28088/ios-sweet), pinned at `8ba152f7132d3c25b5e2ff83b7f5455b8e01457f`. The upstream README reports an iOS 16.7.16 UI with native Adreno 618 Metal rendering, touch/buttons, Wi-Fi/Bluetooth pairing, USB debugging, battery reporting and a writable UFS/HFS+ root. Animation smoothness and multiple services remain incomplete.

Read [`AGENTS.md`](AGENTS.md) before adapting code. The old `codex/native-adreno-metal` branch is no longer tracked here. The fork has no root license, so this is a source-reference submodule only; do not copy or redistribute code without license clarification. All status claims are upstream reports, not Portsmith device verification.
