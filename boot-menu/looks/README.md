# Looks

Each JSON file is a schema-checked, renderer-neutral visual configuration. Layouts describe proportions and colors, not device pixels or hardware backends. `icon-stack` is inspired by the Guacamole menu's shape, not its code or art.

- `icon-stack.json`: vertical icon cards with a selection ring.
- `text-list.json`: accessible/high-contrast keyboard-friendly list.
- `landscape-cards.json`: horizontal two-row cards for wide displays.
