# Generic iOS-version menu badges

`ios-12.svg` through `ios-27.svg` are Portsmith-generated rounded-square version tokens. They use original gradient/vector shapes and the literal labels “iOS” plus a version number. **They are not official Apple app icons, official iOS artwork, or reproductions of Apple wallpapers/logos.** They are suitable as neutral menu identifiers only; do not imply Apple endorsement.

Regenerate with `python3 boot-menu/icons/generate.py`. Profiles refer to them using IDs such as `ios-16` and `ios-27`; UI renderers may substitute a text fallback when assets are unavailable. License of these original Portsmith-generated SVG files: repository-owned work, absent another notice.
