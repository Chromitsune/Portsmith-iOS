# Generic iOS-version menu badges

`ios-12.svg` through `ios-18.svg`, plus `ios-26.svg` and `ios-27.svg`, are Portsmith-generated rounded-square version tokens. Apple skipped major versions 19–25. The badges use original gradient/vector shapes and the literal labels “iOS” plus a version number. **They are not official Apple app icons, official iOS artwork, or reproductions of Apple wallpapers/logos.** They are neutral menu identifiers only; do not imply Apple endorsement.

Regenerate with `python3 boot-menu/icons/generate.py`. Profiles refer to them using IDs such as `ios-16` and `ios-27`; renderers may substitute a text fallback when assets are unavailable.

## Fandom assets not imported

The suggested [Logopedia iOS/Versions page](https://logos.fandom.com/wiki/IOS/Versions) was inspected. Fandom's general text license does not cover images, and the image files inspected did not expose a clear per-file reuse grant. The user indicated the rights are uncertain, so no Fandom image was downloaded or copied. The earlier user-provided sprite sheet is a separate asset and is also not included. Replace these generic badges only after confirming a clear license or rights-holder permission for each asset.
