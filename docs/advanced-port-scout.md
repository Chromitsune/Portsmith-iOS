# Advanced-port scout from UniXNU device pages

This is a selective, read-only scouting note from the public [UniXNU device index](https://unixnu.com/devices/) and linked source/evidence pages, checked 2026-11-22. Portsmith records only public source pins and upstream claims; **none of the upstream hardware results below are Portsmith tests**. Catalog/source pin drift is a review signal, not permission to move a Portsmith pin automatically.

## Added as a separate reference profile: gts7xlwifi

- **Samsung Galaxy Tab S7+ Wi-Fi (SM-T970), SM8250:** [device page](https://unixnu.com/devices/gts7xlwifi), [source](https://github.com/rui12366B/UniXNU-gts7xlwifi), device record/source pin `88b34f97100a01aab4ea6b86dc9c748b2114c382`.
- The pinned record and its device logs describe a full iPadOS 17.7.11 desktop, 8-core SM8250 support, native UFS root/Data with persistent data, Adreno 650-composited UI, touch, speaker audio/microphone, Bluetooth, USB console/device mode, and battery work. The strongest public evidence is `docs/evidence/periph15-bootlog.txt` at run revision `781e3528e2d5e0dc0c9c6fa1e409f5a4bc1cf0e2` and `docs/evidence/main7-bootlog.txt` at `b2cdb153b4f46a3bdaeb2326f326ce5c78adc58d`.
- Keep it separate from Portsmith's existing [`sm-t970`](../ports/sm-t970/README.md) `CakeAL/UniXNU-sm-t970` single-core bootstrap. Same model, different project, build and evidence.
- License in the pinned `LICENSE` is BSD-2-Clause-Patent by default; drivers/kits retain upstream licenses, explicitly MIT-tagged files remain MIT, XNU patches remain APSL-2.0, and proprietary firmware is not included. Firmware itself is not part of the Portsmith source pointer.
- Portsmith added the source as a reference-only profile at [`ports/gts7xlwifi/`](../ports/gts7xlwifi/README.md). Wi-Fi is deliberately **Partial** because the record's summary and its detailed findings do not establish a single consistent qualification level.

## Already present in Portsmith, but worth a fresh pin review

- **Rockchip RK3588 EVB10 V10:** [device page](https://unixnu.com/devices/evb10), current source-record revision `8ae5c74f52aff52adab778561c7e6dac9d31dc78`, [boot-v1 capture](https://github.com/Ken-u/UniXNU-evb10/blob/8ae5c74f52aff52adab778561c7e6dac9d31dc78/evidence/boot-v1-20261030.txt). The current page reports SpringBoard on eMMC, touch and Mali-G610 composition, with a 235-second scripted swipe run at about 52.6 fps and no panic/stalled GPU group. Portsmith already has [`ports/evb10/`](../ports/evb10/README.md) at the older catalog snapshot pin `37befa9162d6b4b080cb63a95cccff0ebb4d34f5`; the source's BSD-2-Clause-Patent license does not blanket-license its dependencies, XNU patches, firmware or OS assets. Review drift before changing the pin.
- **Samsung Galaxy S9, starlte / Exynos 9810 (HakiOS, not UniXNU):** [device page](https://unixnu.com/devices/starlte), current record `077d97f29fbbba873ce4f6235b5f293530f421af`. It describes device runs with six cores, SpringBoard/touch, Mali-G72 Panfrost UI, Wi-Fi DHCP/Internet, speaker audio and a 30 fps front-camera preview. Some sensor/Bluetooth/mic evidence is “seen but not default”; underlying USB captures are private, so public evidence consists of pinned maintainer summaries. Portsmith already has [`ports/starlte/`](../ports/starlte/README.md) at `76bbd6000aeea88c4da5e3e0cdc2225178d1eac0`; keep the HakiOS source/evidence separate from UniXNU and review the newer record pin before updating. License boundary from its repo: MIT device layer, BSD-2-Clause-Patent UEFI-derived changes, GPL-2.0 Carbon, APSL-2.0 common kernel, and separately owned Samsung/Broadcom firmware.

## Promising, but not added as a source checkout

- **Benesse TAB-A04-BR3 / MT8167:** [device page](https://unixnu.com/devices/a04br3), current record `bd68ad730a2ec743ae658d8c3c4631a9730a8ff6`, source [`mouseos/UniXNU-a04br3`](https://github.com/mouseos/UniXNU-a04br3) at `a8905ba1997530ea9afb871ed999435580ea80a1`. The page/README reports iPadOS home screen, four CPUs, eMMC DMA, CPU framebuffer and PowerVR Vulkan transfer/readback; it explicitly does **not** establish Metal UI acceleration/full 3D performance or give an exact device-run date. The public repo has no recognized root reuse license, so Portsmith leaves it metadata-only and does not initialize/copy its code unless licensing is clarified.

The full device page is dynamic and the source records are independently versioned. Re-check the source commit, per-file notices, firmware boundary, and raw evidence before adding any further source or upgrading an evidence status.
